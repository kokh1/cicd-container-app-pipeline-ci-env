# gitlab
This repo contains files for configuring Gitlab CE locally, a local runner and a local registry.

+ For full project information and README, see the main project repo (https://github.com/kokh1/cicd-container-app-pipeline)

+ config/, data/, logs/, and flask-app-template/ are empty placeholder directories for mounted volumes that get created automatically. They are .gitignored in this repo. 
    + Actual data lives in the named Docker volumes or bind mounts.

+ .example versions of sensitive files are included for reference.
